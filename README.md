# 不要說今天很閒

復健科診所物理治療師值班模擬遊戲。熱敷、短波、電療、雷射、拉腰、拉脖子同時在嗶，每位病人處方都不一樣，而你只有一個人。記得喝水、上廁所，撐過這一診。

- 早診、午診、晚診三種班別，標準速度一局約 6–7 分鐘（可切換慢／快）
- 熱敷區、冰敷區分開，急性受傷的病人改冰敷
- 牽引前要先熱敷，上機要親自擺位
- 隨機事件與禁忌症判斷
- 突發狀況：跳電、機器故障、熱敷箱水位低、主任巡房、櫃台當機、長輩團報到
- 口渴、膀胱、腰痛要自己顧
- 原創背景音樂（可在右上角關閉），病人潮時節奏會變快
- 結算給 A／B／C 等級

單一 HTML 檔，直接用瀏覽器打開 `index.html` 就能玩。病人、處方、床位數量和事件都放在程式最上方的設定區，可以直接修改。
