# 不要說今天很閒

復健科診所物理治療師值班模擬遊戲。熱敷、短波、電療、雷射、拉腰、拉脖子同時在嗶，每位病人處方都不一樣，而你只有一個人。記得喝水、上廁所，撐過這一診。

- 早診、午診、晚診三種班別，標準速度一局約 6–7 分鐘（可切換慢／快）
- 冰敷還是熱敷由玩家依症狀判斷：有紅腫熱痛就冰敷，慢性痠痛就熱敷
- 做過熱敷的病人不做短波
- 熱敷要用乾淨毛巾：用過要洗（洗衣機約 15 分鐘）、洗好要折，沒有乾淨毛巾就不能熱敷（開診 8 條）
- 冰袋共 10 個，用過要放回冷凍庫冷卻 15 分鐘
- 超音波、徒手治療（各 5 分鐘）要治療師親自做，可中途離開、回來繼續；超音波、雷射擇一
- 急性期（紅腫熱痛）一律安排雷射
- 每一診最多 45 位病人
- 病人更多元：只會英文／日文的外國人、越南新住民、印尼看護陪同、只聽得懂台語的阿公阿嬤（要選翻譯方式）、孕婦（不能電療、短波、拉腰）、坐輪椅的中風病人、運動拉傷的學生
- 下班前 1 小時停止掛號，整點準時下班，沒做完的治療每項扣分
- 熱敷完要馬上牽引，中間不能插別的項目；超音波、徒手擇一
- 牽引前要先熱敷，上機要親自擺位
- 每做完一項，由玩家決定病人下一站
- 叫號燈與病人走位動畫：病人沿走廊走到指定床位，做完走回候診區批價
- 隨機事件與禁忌症判斷
- 突發狀況：跳電、機器故障、熱敷箱水位低、主任巡房、櫃台當機、長輩團報到、電療貼片掉了、雷射探頭滑掉
- 口渴、膀胱、腰痛、體力要自己顧；可以喝咖啡、吃零食補體力（家屬送的鳳梨酥可以婉拒）；體力剩一半動作變慢，歸零會累到走不動
- 原創背景音樂，早、午、晚診各一首（可在右上角關閉），病人潮時節奏會變快
- 結算給 A／B／C 等級
- 挑戰碼：同一組 4 位數代碼＋同一個班別，會遇到一樣的病人與突發狀況；也有每日挑戰碼。分享連結格式：`#am4821`（am 早診、pm 午診、eve 晚診）

單一 HTML 檔，直接用瀏覽器打開 `index.html` 就能玩。病人、處方、床位數量和事件都放在程式最上方的設定區，可以直接修改。
